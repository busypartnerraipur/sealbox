Uninstalling Sealbox

To uninstall Sealbox on Windows XP, select Start menu > Settings > Control Panel > Add or Remove Programs> Sealbox > Change/Remove.

To uninstall Sealbox on Windows Vista or later, select Start menu > Computer > Uninstall or change a program > Sealbox > Uninstall.

To uninstall Sealbox on Linux, you have to run the following command as root: veracrypt-uninstall.sh. For example, on Ubuntu, you can type the following in Terminal: sudo veracrypt-uninstall.sh

No Sealbox volume will be removed when you uninstall Sealbox. You will be able to mount your Sealbox volume(s) again after you install Sealbox or when you run it in portable mode.
